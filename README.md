# Misfit Lessons

A collection of standalone, cross-disciplinary computational worksheets, diagnostic lab notebooks, and exploratory lessons in statistics, information theory, and machine learning that don't fit neatly into a single course curriculum.

---

## Catalog of Lessons

### 1. Wald's Sequential Probability Ratio Test (SPRT)
- **Worksheet Notebook**: [`wald_sprt_worksheet.ipynb`](wald_sprt_worksheet.ipynb)
- **Standalone Script**: [`wald_sprt_example.py`](wald_sprt_example.py)
- **Core Topics**: Sequential hypothesis testing, optimal stopping times, martingale scorekeeping, and relative entropy ($D_{\text{KL}}$) as physical information drift.
- **Why It's a "Misfit"**: It connects the **Bayesian Inference** track (comparing $t$-tests and sequential decision theory in Ch 11 & Ch 19) directly to the **Information Theory** track (relative entropy velocity in Ch 03 and active learning in Ch 10).
